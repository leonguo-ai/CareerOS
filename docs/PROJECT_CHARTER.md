# CareerOS Project Charter

## 最终目标

CareerOS 用于自动发现网络上仍在开放的校招、提前批和实习岗位，自动识别、去重和匹配岗位，每天筛选最值得投递的20个岗位，根据真实经历生成定制简历，并在人工审核后进行合规投递。

## 核心工作流

1. 自动发现岗位
2. 判断开放状态
3. 岗位去重
4. 识别硬性条件
5. 与主简历匹配
6. 生成每日 Top 20
7. 生成定制简历和申请材料
8. 事实一致性检查
9. 人工审核
10. 自动填写并合规提交
11. 跟踪投递、测评、笔试、面试和 Offer

## 安全与真实性原则

- 不虚构经历、技能、学校、证书或业务成果
- 不擅自修改真实数据
- 不绕过验证码、登录验证或网站风控
- 遵守招聘网站使用规则
- 正式提交申请前必须人工审核
- 手机号、邮箱、完整简历和 API Key 不进入公开仓库

## 每日目标

每天筛选并精心投递最多20个高匹配岗位，而不是无差别海投。
